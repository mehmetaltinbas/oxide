# Fonts

Bangers and Comic Neue, the same two faces the browser game used, in TrueType
because that is what SDL reads. Both are under the SIL Open Font License 1.1,
which allows bundling and redistribution inside a product like this one,
including commercially, so long as the fonts themselves are not sold on their
own and LICENCE.md travels with them.

`display` shouts and `body` is read: most of this game's text is drawn at ten
to twelve pixels, and a comic display face is illegible that small.
